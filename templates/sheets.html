Cómo crear las credenciales (una sola vez)
  1. Andá a console.cloud.google.com → creá un proyecto nuevo.
  2. Activá la Google Sheets API y la Google Drive API.
  3. Creá una Cuenta de servicio: IAM → Credenciales → + Crear credenciales.
  4. Generá una clave JSON: click en la cuenta → Claves → Agregar clave → JSON.
  5. Abrí tu spreadsheet → Compartir → pegá el email de la service account → Rol: Editor.
  6. Subí el JSON en el Paso 3 de arriba.
